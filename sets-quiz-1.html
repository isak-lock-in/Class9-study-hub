1. Which of the following is a well-defined set?

💡 Explanation:

“Months having 31 days” gives an objective condition. Every month can be checked to see whether it belongs to the set.

2. If A = {2, 4, 6, 8, 10}, what is n(A)?

💡 Explanation:

A contains 2, 4, 6, 8 and 10. Therefore it has 5 elements.

n(A) = 5

3. If A = {1, 2, 3} and B = {3, 4, 5}, what is A ∩ B?

💡 Explanation:

The intersection contains elements common to both sets. The only common element is 3.

A ∩ B = {3}

4. If A = {1, 2, 3} and B = {3, 4, 5}, what is A ∪ B?

💡 Explanation:

The union contains every distinct element from both sets.

A ∪ B = {1, 2, 3, 4, 5}

5. Let U = {1,2,3,4,5,6,7,8} and A = {2,4,6,8}. What is Ac?

💡 Explanation:

The complement contains elements of U that are not in A.

Ac = {1,3,5,7}

6. Which statement is always true for any set A?

💡 Explanation:

Every element of A is common to A itself. Therefore:

A ∩ A = A

7. A class has 20 students. 12 like Mathematics, 9 like Science, and 5 like both. How many like at least one subject?

💡 Explanation:

Use:

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)

= 12 + 9 − 5
= 16

8. If A = {1,2,3,4} and B = {3,4,5,6}, how many elements are in A ∪ B?

💡 Explanation:

A ∪ B = {1,2,3,4,5,6}

Therefore there are 6 elements.

9. If A has 7 elements, B has 5 elements, and A ∩ B has 2 elements, how many elements are in A ∪ B?

💡 Explanation:

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)

= 7 + 5 − 2
= 10

10. If U has 15 elements and A has 9 elements, how many elements are in Ac?

💡 Explanation:

n(Ac) = n(U) − n(A)

= 15 − 9
= 6
