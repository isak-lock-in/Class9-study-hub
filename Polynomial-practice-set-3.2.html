Practice Set 3.2 — Operations and identities.

🟢 Problem 1 — Easy

1. Adding Polynomials

Add:

(3x + 7) + (5x − 2)


💡 Step-by-step solution:

Combine like terms:

3x + 5x = 8x
7 − 2 = 5

Therefore: 8x + 5
🟢 Problem 2 — Easy/Medium

2. Subtracting Polynomials

Simplify:

(7x2 + 3x − 4) − (2x2 − x + 5)


💡 Step-by-step solution:

Distribute the minus sign:

7x2 + 3x − 4 − 2x2 + x − 5

Combine like terms:
7x2 − 2x2 = 5x2
3x + x = 4x
−4 − 5 = −9

Answer = 5x2 + 4x − 9
🟡 Problem 3 — Medium

3. Multiplication

Expand:

4x(2x2 − 3x + 5)


💡 Step-by-step solution:

Multiply 4x by every term:

4x × 2x2 = 8x3
4x × (−3x) = −12x2
4x × 5 = 20x

Therefore: 8x3 − 12x2 + 20x
🟠 Problem 4 — Hard

4. Identity Challenge

Simplify:

(x + 6)2


💡 Step-by-step solution:

Use:
(a + b)2 = a2 + 2ab + b2

Here:
a = x, b = 6

Therefore:
x2 + 12x + 36

Answer = x2 + 12x + 36
🔴 Problem 5 — Challenge

5. Difference of Squares

Simplify:

(3x + 5)(3x − 5)


💡 Step-by-step solution:

Use:
(a + b)(a − b) = a2 − b2

Here:
a = 3x
b = 5

Therefore:
(3x)2 − 52
= 9x2 − 25

Answer = 9x2 − 25
