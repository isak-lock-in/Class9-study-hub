1. Which of the following is an irrational number?

Attempts remaining: 2
Step-by-step solution 🧠
0.75 = 75/100, so it is rational.

-4 can be written as -4/1, so it is rational.

3/5 is already in fraction form, so it is rational.

√2 cannot be expressed as p/q where p and q are integers.

Therefore, √2 is irrational.

2. Which fraction has a terminating decimal expansion?

Attempts remaining: 2
Step-by-step solution 🧠
A rational number has a terminating decimal when, in lowest form, its denominator contains only the prime factors 2 and/or 5.

20 = 2 × 2 × 5

Therefore 7/20 has a terminating decimal.

7/20 = 0.35

3. Simplify: √72

Attempts remaining: 2

√72

= √(36 × 2)

= √36 × √2

4. Which statement is true?

Attempts remaining: 2
Step-by-step solution 🧠
Any integer can be written as a fraction with denominator 1.

For example:
5 = 5/1
-3 = -3/1

Therefore every integer is rational.

Answer: Every integer is a rational number.

5. What is the value of |−13|?

Attempts remaining: 2
Step-by-step solution 🧠
Absolute value represents distance from zero.

The distance of -13 from zero is 13.

Therefore:

|−13| = 13

Answer: 13
