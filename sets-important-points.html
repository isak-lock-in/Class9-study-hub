⭐ Sets — Important Points

Quick revision of the most important concepts from Chapter 1.

📦 Set

A set is a well-defined collection of objects called elements.

📝 Listing Method

Write all the elements inside curly brackets.

Example: A = {1, 2, 3, 4}

🧮 Set-Builder Method

Describe a set using a rule or condition satisfied by its elements.

🟰 Equal Sets

Two sets are equal when they contain exactly the same elements.

The order of elements does not matter.

📊 Finite & Infinite Sets

Finite: Has a limited number of elements.

Infinite: Has endlessly many elements.

🔗 Subset

B is a subset of A if every element of B is also an element of A.

B ⊆ A

🌐 Universal Set

The universal set contains all the elements being considered.

It is commonly represented by U.

⭕ Venn Diagram

Venn diagrams represent sets using closed shapes such as circles.

The rectangle usually represents the universal set.

🔄 Complement

The complement of A contains elements in U that are not in A.

A′ = U − A

➕ Union

The union contains every element belonging to A or B.

A ∪ B

Common elements are written only once.

✖️ Intersection

The intersection contains elements common to both sets.

A ∩ B

⚠️ Remember

Do not repeat an element when listing a set.

Order does not determine whether two sets are equal.

Always check the universal set before finding a complement.
