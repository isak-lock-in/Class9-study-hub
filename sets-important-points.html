CHAPTER 1

Sets

Important definitions, properties, formulas and quick revision points.

1. Definition of a Set

A set is a well-defined collection of distinct objects. The objects in a set are called elements or members.

Example: A = {1, 2, 3, 4}
💡 A set must have a clear rule for deciding whether an object belongs to it.

2. Representation of Sets

Roster Form

A = {2, 4, 6, 8}

The elements are listed inside curly brackets.

Set-Builder Form

A = {x : x is an even natural number less than 10}

The common property of the elements is described.

3. Types of Sets

  • Empty set: Contains no elements.
  • Singleton set: Contains exactly one element.
  • Finite set: Has a definite number of elements.
  • Infinite set: Has infinitely many elements.
Empty set = ∅

Singleton example = {5}

4. Equal Sets

Two sets are equal if they contain exactly the same elements.

A = {1, 2, 3}
B = {3, 1, 2}

Therefore A = B
💡 The order in which elements are written does not matter.

5. Subsets

A is a subset of B if every element of A is also an element of B.

A ⊆ B
A = {1, 2}
B = {1, 2, 3}

A ⊆ B
💡 Every set is a subset of itself.

6. Power Set

The power set contains all the subsets of a set.

If A = {1, 2}

P(A) = {∅, {1}, {2}, {1,2}}
If n(A) = n,

n(P(A)) = 2ⁿ

7. Universal Set

The universal set contains all objects being considered in a particular situation.

U = Universal Set
For numbers from 1 to 5:

U = {1, 2, 3, 4, 5}

8. Union

The union contains every distinct element belonging to either of the two sets.

A ∪ B
A = {1,2,3}
B = {3,4,5}

A ∪ B = {1,2,3,4,5}

9. Intersection

The intersection contains elements common to both sets.

A ∩ B
A = {1,2,3}
B = {3,4,5}

A ∩ B = {3}

10. Difference of Sets

A − B contains elements that belong to A but do not belong to B.

A − B
A = {1,2,3,4}
B = {3,4,5}

A − B = {1,2}
💡 A − B and B − A are generally different.

11. Complement of a Set

The complement of A contains elements of the universal set that are not in A.

Aᶜ = U − A
U = {1,2,3,4,5}
A = {2,4}

Aᶜ = {1,3,5}

12. Number of Elements

n(A) represents the number of elements in A.

A = {2,4,6,8}

n(A) = 4

Important Union Formula

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)
💡 The intersection is subtracted because common elements would otherwise be counted twice.

13. Venn Diagrams

Venn diagrams use closed shapes to visually represent sets and their relationships.

  • Overlapping region → intersection
  • Combined regions → union
  • Outside a set but inside U → complement

14. Important Properties

A ∪ A = A

A ∩ A = A

A ∪ ∅ = A

A ∩ ∅ = ∅

A ∪ U = U

A ∩ U = A

15. Quick Revision

  • A set is a well-defined collection of distinct objects.
  • Elements are written inside curly brackets.
  • ∅ represents the empty set.
  • A ⊆ B means every element of A belongs to B.
  • The power set contains every subset.
  • A ∪ B contains elements from A or B.
  • A ∩ B contains elements common to A and B.
  • A − B contains elements in A but not B.
  • Aᶜ contains elements of U that are not in A.
  • n(A) gives the number of elements in A.
  • Venn diagrams show relationships between sets.
