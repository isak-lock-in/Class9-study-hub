Algebra
Important Points

Quick revision • Key rules • Exam prep 📚

🔥 Must Remember

Like terms → same variables + same powers.

Indices multiply → add powers.

Indices divide → subtract powers.

Same signs → positive when multiplying/dividing.

Different signs → negative when multiplying/dividing.


🔢 Number Basics

Absolute value:

|−7| = 7

Remember: Absolute value is always non-negative.

BODMAS:

Brackets → Orders → Division → Multiplication → Addition → Subtraction

🔺 Indices

Multiplication:

am × an = am+n

Division:

am ÷ an = am−n

Power of a power:

(am)n = amn

Product power:

(ab)m = ambm

Zero index:

a0 = 1

Negative index:

a−n = 1/an

➕➖ Integers

Same signs:
Add the numbers and keep the sign.

Different signs:
Subtract the smaller absolute value from the larger and keep the sign of the number with the larger absolute value.

Multiplication & division:

+ × + = +

− × − = +

+ × − = −

− × + = −

🔢 Polynomials

Term: Each part separated by + or −.

Coefficient: Numerical factor of a term.

Constant: A term without a variable.

Degree: Highest power of the variable.

Like terms: Same variables with the same powers.

Monomial: One term.

Binomial: Two terms.

Trinomial: Three terms.

🧮 Algebraic Expressions

Only combine like terms.

3x + 5x = 8x

3x + 5 cannot become 8x because they are not like terms.

Distributive property:

a(b + c) = ab + ac

Be careful when removing brackets containing a negative sign.

📐 Algebraic Identities

(a + b)2 = a2 + 2ab + b2

(a − b)2 = a2 − 2ab + b2

a2 − b2 = (a − b)(a + b)

(a + b)(a − b) = a2 − b2

✖️ Sign Rules

+ × + = +

− × − = +

+ × − = −

− × + = −

Remember: Same signs give positive. Different signs give negative.

⚠️ Common Mistakes

❌ 3x + 4 = 7x

✅ Only like terms can be combined.

❌ (a + b)2 = a2 + b2

✅ Remember the 2ab term.

❌ am + an = am+n

✅ Index addition rules apply to multiplication, not ordinary addition.
