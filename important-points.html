Important Points

Quick revision • Key rules • Exam prep 📚

🔺 Indices

Same base — multiplication:

am × an = am+n

Same base — division:

am ÷ an = am−n

Power of a power:

(am)n = amn

Zero index:

a0 = 1

Negative index:

a−n = 1/an

➕➖ Integers

Same signs:
Add the numbers and keep the sign.

Different signs:
Subtract the smaller absolute value from the larger and keep the sign of the number with the larger absolute value.

Multiplication & division:

+ × + = +

− × − = +

+ × − = −

− × + = −

🔢 Polynomials

Term: Each part of an expression separated by + or −.

Coefficient: The numerical factor of a term.

Constant: A term without a variable.

Degree: The highest power of the variable.

Like terms: Terms having the same variables with the same powers.

🧮 Algebraic Expressions

Rule: Only combine like terms.

3x + 5x = 8x

3x + 5 cannot be simplified to 8x because they are not like terms.

📐 Algebraic Identities

(a + b)2 = a2 + 2ab + b2

(a − b)2 = a2 − 2ab + b2

a2 − b2 = (a − b)(a + b)

✖️ Sign Rules

+ × + = +

− × − = +

+ × − = −

− × + = −

Remember: Same signs give positive; different signs give negative.
