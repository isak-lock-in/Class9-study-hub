📚 Algebra Basics

What is Algebra?

Algebra is a branch of mathematics where letters and symbols are used to represent numbers.

🔤 Variables

A variable is a letter that represents an unknown value.

Example: x + 5 = 12

Here, x is the variable.

🔢 Constants

A constant is a fixed number.

Example: 3x + 7

Here, 7 is the constant.
