📖 Chapter 1: Sets

Learn the important concepts of Sets step by step.


🔹 Introduction to Sets

A set is a well-defined collection of objects or elements.

Example: A = {2, 4, 6, 8}

The numbers 2, 4, 6 and 8 are the elements of set A.

📝 Listing / Roster Method

In the listing method, all the elements of a set are written inside curly brackets and separated by commas.

Example: A = {1, 2, 3, 4, 5}

Repeated elements are generally written only once.

🧮 Rule / Set-Builder Method

In the rule method, a set is described using a condition that every element in the set satisfies.

Example: A = {x | x is an even natural number less than 10}

This represents the set: {2, 4, 6, 8}

🟰 Equal Sets

Two sets are equal when they contain exactly the same elements.

The order in which elements are written does not matter.

Example: A = {1, 2, 3}

B = {3, 1, 2}

Therefore, A = B.

📦 Finite & Infinite Sets

A finite set has a limited number of elements.

Example: A = {10, 20, 30, 40}

An infinite set has endlessly many elements.

Example: N = {1, 2, 3, 4, 5, ...}

⭕ Venn Diagrams

A Venn diagram represents sets using closed shapes, usually circles, inside a rectangle representing the universal set.

They help us visualize relationships between sets.

🔗 Subsets

Set B is a subset of set A if every element of B is also an element of A.

It is written as: B ⊆ A

Example: A = {1, 2, 3, 4}

B = {1, 3}

Therefore: B ⊆ A

🌐 Universal Set

The universal set contains all the elements being considered in a particular situation.

It is commonly represented by U.

🔄 Complement of a Set

The complement of A contains the elements of the universal set that are not in A.

It can be written as A' or Aᶜ.

Example: U = {1, 2, 3, 4, 5}

A = {1, 3, 5}

A' = {2, 4}

➕ Union of Sets

The union of two sets contains every element that belongs to either set, without repeating common elements.

It is written as: A ∪ B

✖️ Intersection of Sets

The intersection of two sets contains only the elements common to both sets.

It is written as: A ∩ B
