📖 Chapter 1: Sets

Learn the important concepts of Sets step by step.

🔹 Introduction to Sets

A set is a well-defined collection of objects or elements.

Example: A = {2, 4, 6, 8}

The numbers 2, 4, 6 and 8 are the elements of set A.

📝 Listing / Roster Method

In the listing method, all the elements of a set are written inside curly brackets and separated by commas.

Example: A = {1, 2, 3, 4, 5}

📕 Rule / Set-Builder Method

In the rule method, the elements of a set are described using a rule or condition.

Example: A = {x | x is an even natural number less than 10}

🟰 Equal Sets

Two sets are equal when they contain exactly the same elements, regardless of the order in which the elements are written.

A = {1, 2, 3}

B = {3, 1, 2}

Therefore, A = B.

📦 Finite & Infinite Sets

A set having a definite number of elements is called a finite set.

A set whose number of elements cannot be counted is called an infinite set.

Finite: {1, 2, 3, 4, 5}

Infinite: {1, 2, 3, 4, 5, ...}

⭕ Venn Diagrams

Venn diagrams represent sets using closed figures, usually circles. They help us understand relationships between sets visually.

🔗 Subsets

Set B is a subset of set A if every element of B is also an element of A.

B ⊆ A

🌐 Universal Set

The universal set contains all the elements being considered in a particular situation.

↪️ Complement of a Set

The complement of set A contains all the elements of the universal set that are not present in A.

A′ = U − A

➕ Union of Sets

The union of two sets contains all elements that belong to either set, without repeating common elements.

A ∪ B

✖️ Intersection of Sets

The intersection of two sets contains only the elements that are common to both sets.

A ∩ B
