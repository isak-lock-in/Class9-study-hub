CHAPTER 2

Real Numbers

Important definitions, properties, formulas and quick revision points.

1. Number Classification

Natural ⊂ Whole ⊂ Integers ⊂ Rational ⊂ Real
  • Natural numbers: 1, 2, 3, ...
  • Whole numbers: 0, 1, 2, 3, ...
  • Integers: ..., −2, −1, 0, 1, 2, ...
  • Rational numbers can be written as p/q, q ≠ 0.
  • Irrational numbers cannot be written as p/q.

2. Rational Numbers

x = p/q, where p,q ∈ ℤ and q ≠ 0

Rational numbers include integers, fractions and terminating or recurring decimals.

💡 Every integer is rational because it can be written with denominator 1.

3. Decimal Expansion

Terminating

The decimal ends after a finite number of digits.

1/4 = 0.25

Non-terminating recurring

The decimal continues forever but follows a repeating pattern.

1/3 = 0.333...
💡 For a rational number in lowest form, a terminating decimal occurs when the denominator has only 2 and/or 5 as prime factors.

4. Irrational Numbers

  • Cannot be expressed as p/q.
  • Decimal expansion is non-terminating.
  • Decimal expansion is non-recurring.
Examples: √2, √3, √5, π

5. Real Numbers

Real Numbers = Rational Numbers ∪ Irrational Numbers

Every point on the real number line represents a real number.

6. Square Roots

The square root of a positive number is a value whose square gives that number.

√25 = 5

because 5² = 25
💡 Before working with a square root, check whether the number has a perfect-square factor.

7. Surds

A surd is an irrational root that cannot be simplified into a rational number.

√2, √3, √5
⚠️ Do not call every square root a surd. For example, √25 = 5 is rational, so it is not a surd.

8. Simplifying Surds

Take perfect-square factors outside the radical.

√12 = √(4 × 3) = 2√3

√50 = √(25 × 2) = 5√2

9. Operations on Surds

Addition and Subtraction

3√2 + 5√2 = 8√2

Only like surds can be directly combined.

Multiplication

√a × √b = √(ab)

Division

√a / √b = √(a/b)

10. Rationalization

Rationalization removes an irrational quantity from the denominator.

1/√2 × √2/√2 = √2/2

Conjugates

Conjugate of (a + √b) = (a − √b)
💡 When a denominator contains a binomial surd, multiplying by its conjugate is often the key step.

11. Absolute Value

Absolute value represents the distance of a number from zero on the number line.

|5| = 5

|−5| = 5

|0| = 0
⚠️ Absolute value can never be negative.

12. Quick Formula Sheet

Rational number = p/q, q ≠ 0

Real = Rational ∪ Irrational

√a × √b = √ab

|x| ≥ 0

13. Exam Checklist

  • Know the difference between rational and irrational numbers.
  • Know how to identify terminating decimals.
  • Know how to identify recurring decimals.
  • Be able to simplify quadratic surds.
  • Know which surds are like surds.
  • Practice multiplication and division of surds.
  • Understand rationalization.
  • Know conjugate pairs.
  • Remember that |x| is never negative.
