01 • Learn

Value of a Polynomial

The value of a polynomial is found by replacing its variable with the given number and simplifying carefully.

What does “value” mean?

Suppose we have a polynomial p(x). If a number is given for x, substitute that number everywhere x appears. Then simplify using the correct order of operations.

p(a) = polynomial after replacing x with a Substitute first → simplify second

Example

Let p(x) = 2x² − 3x + 5 and suppose x = 2.

p(2) = 2(2²) − 3(2) + 5 = 8 − 6 + 5 = 7

Therefore, the value of the polynomial at x = 2 is 7.

①

Substitute everywhere

Replace every occurrence of the variable, not just the first one.

②

Watch negative values

If x is negative, use brackets while substituting, especially for powers.

③

Simplify carefully

Powers come before multiplication and addition. Follow the order of operations.

02 • Important Points

Lock these in.

These are the mistakes that can cost easy marks.

POINT 01

Negative substitution

For x = −2, write (−2)², not −2². The brackets matter.

POINT 02

Don't skip terms

Every term containing the variable must receive the substitution.

POINT 03

Calculate powers first

Evaluate x², x³ and other powers before combining the terms.

POINT 04

Keep signs visible

Rewrite the expression after substitution so that positive and negative signs are easy to track.

POINT 05

p(a) means substitute a

The notation p(a) simply tells you that the variable should be replaced by a.

POINT 06

Check your answer

Quickly substitute your final value again if the calculation looked suspicious.

Question 01

If p(x) = 3x² − 4x + 7, find p(2).

Try it yourself before revealing the solution.

Solution:
p(2) = 3(2²) − 4(2) + 7
= 3(4) − 8 + 7
= 12 − 8 + 7
= 11
Question 02

If p(y) = y² − 5y + 2, find p(−3).

Be especially careful with the square of −3.

Solution:
p(−3) = (−3)² − 5(−3) + 2
= 9 + 15 + 2
= 26
Question 03

If p(t) = 2t³ + t² − 3t + 1, find p(−1).

Rewrite each substitution with brackets.

Solution:
p(−1) = 2(−1)³ + (−1)² − 3(−1) + 1
= −2 + 1 + 3 + 1
= 3
Question 04

If p(m) = m³ − 2m² + 6, find p(3).

There is no m-term in the middle. Don't accidentally create one.

Solution:
p(3) = 3³ − 2(3²) + 6
= 27 − 18 + 6
= 15
