Chapter 1: Sets

Original practice questions on set representation and notation.

🟢 Question 1 — Easy

Write the set of positive even integers less than 15 in roster form.


Start with 2 and keep adding 2 until you reach a number below 15.

Step 1: List the positive even integers.

2, 4, 6, 8, 10, 12, 14

Step 2: All of them are less than 15.

Answer: {2, 4, 6, 8, 10, 12, 14}

🟢 Question 2 — Easy → Medium

Write the set of vowels in the English alphabet using roster notation.


Think of the five basic vowel letters.

Step 1: Identify the vowels.

a, e, i, o, u

Step 2: Put them inside curly brackets.

Answer: {a, e, i, o, u}

🟡 Question 3 — Medium

Write the following set in roster form:

A = {x | x is a natural number greater than 3 and less than 9}


Find the natural numbers between 3 and 9.

Step 1: Natural numbers greater than 3 are:

4, 5, 6, 7, 8, ...

Step 2: Keep only numbers less than 9.

Answer: {4, 5, 6, 7, 8}

🟠 Question 4 — Hard

Write the following set in set-builder form:

B = {5, 10, 15, 20, 25}


Look for a common pattern between the numbers.

Step 1: Every element is a multiple of 5.

Step 2: The values go from 5 through 25.

Answer: B = {x | x is a multiple of 5 and 5 ≤ x ≤ 25}

🔴 Question 5 — Hardest

Decide whether the following statement is true or false:

{2, 4, 6} = {6, 4, 2}


Does the order of elements matter in a set?

Step 1: Both sets contain 2, 4 and 6.

Step 2: The order of elements does not matter in a set.

Answer: True
