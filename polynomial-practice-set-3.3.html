Practice Set 3.3 — Division of polynomials.

🟢 Problem 1 — Easy

1. Dividing a Monomial

Simplify:

12x4 ÷ 3x


💡 Step-by-step solution:

Divide the coefficients:
12 ÷ 3 = 4

For the variable:
x4 ÷ x = x3

Therefore: 4x3
🟢 Problem 2 — Easy/Medium

2. Dividing by a Monomial

Simplify:

(15x3 − 10x2 + 5x) ÷ 5x


💡 Step-by-step solution:

Divide each term by 5x:

15x3 ÷ 5x = 3x2
−10x2 ÷ 5x = −2x
5x ÷ 5x = 1

Therefore: 3x2 − 2x + 1
🟡 Problem 3 — Medium

3. Quotient and Remainder

When:

x2 + 5x + 7

is divided by x + 2, find the remainder.


💡 Step-by-step solution:

For divisor x + 2, put:
x = −2

Substitute:
(−2)2 + 5(−2) + 7
= 4 − 10 + 7
= 1

Therefore: Remainder = 1
🟠 Problem 4 — Hard

4. Finding a Quotient

Divide:

x2 + 7x + 12

by x + 3.


💡 Step-by-step solution:

We need two terms whose product gives:
x2 + 7x + 12

Notice:
(x + 3)(x + 4)
= x2 + 7x + 12

Therefore: Quotient = x + 4
🔴 Problem 5 — Challenge

5. Division Check

A polynomial P(x) is divided by x − 4.

If P(4) = 9, what is the remainder?


💡 Step-by-step solution:

When a polynomial P(x) is divided by x − a, the remainder is P(a).

Here:
a = 4
P(4) = 9

Therefore: Remainder = 9
